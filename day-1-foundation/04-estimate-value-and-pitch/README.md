# Exercise: Estimate Value and Pitch

## Exercise Overview

- **เป้าหมาย:** เปลี่ยนแนวคิดให้เป็นสมมติฐานที่วัดได้และสื่อสารได้ในเวลาสั้น
- **ผลลัพธ์:** AI Use Canvas 

## Prerequisites

- [AI Use Canvas](https://raw.githubusercontent.com/teerasej/mini-m365-copilot-champion-1/main/templates/AI%20Use%20Canvas%20Template.pptx)



### Practice 1: เรียนรู้ใช้งาน AI Use Canvas

![alt text](image.png)

#### Steps

1. ใช้ AI Use Canvas เพื่อประมาณค่า value ของ initiative ของพวกเรา
2. ดาวน์โหลด AI Use Canvas (PPTX): [Raw GitHub Link](https://raw.githubusercontent.com/teerasej/mini-m365-copilot-champion-1/main/templates/AI%20Use%20Canvas%20Template.pptx)
3. ทำความเข้าใจแต่ละหัวข้อของ AI Use Canvas และช่วยกันเติมรายละเอียดเท่าที่เรามีลงในแต่ละหัวข้อ เช่น Work outcome, Business impact, Measurment
4. **สามารถเขียนรายละเอียดของ AI Use Canvas ลงใน post-it ข้อละ 1 แผ่น และแปะลงใน flipchart ที่จัดเตรียมเพื่อให้เห็นภาพรวมกันได้ท้ั้งกลุ่ม**
5. ไล่พิจารณาที่ละหัวข้อจนครบ


### Practice 2: Pitching the AI Use Canvas

#### Steps

1. เตรียม pitch AI Use Canvas ให้ท่านผู้ตรวจการจากกลุ่มอื่น (Checker) ฟัง 
2. ให้คนในกลุ่มคอยสังเกตและจด feedback ที่ได้จากผู้ตรวจการลงใน AI Use Canvas ของพวกเรา เช่นถามอะไร สงสัยตรงไหน หรือมีข้อเสนอแนะอะไรบ้าง
3. ปรับปรุง และเพิ่มเติมรายละเอียดของ AI Use Canvas ให้สมบูรณ์ขึ้นตาม feedback ที่ได้รับ
4. หลังจากปรับปรุงแล้ว เรียกท่านผู้ตรวจการคนเดิมมาตรวจดูว่า AI Use Canvas มีความชัดเจนขึ้นหรือไม่ 
   - ถ้าดีขึ้นแล้ว ให้ท่านผู้ตรวจการเซ็นสัญลักษณ์ และเลขกลุ่มไว้ใน AI Use Canvas ของพวกเรา

> กิจกรรมนี้ สามารถ ทำซ้ำขั้นตอนที่ 1–3 อีก 1 รอบได้ โดยให้ไปหาท่านผู้ตรวจการจากอีกกลุ่ม (ที่ไม่ซ้ำกับกลุ่มเดิม)
   


## Expected Output

AI Use Canvas ที่มี value hypothesis, feedback, first experiment และ pitch 5 นาที
